# לקוח React

הוראות ההתקנה והפקודות המשותפות נמצאות ב־[README הראשי](../README.md).

- `src/App.jsx`: נתיבים וכותרת הניווט.
- `src/context/AuthContext.jsx`: טעינת התחברות, אימות מול השרת והתנתקות.
- `src/services/recipes.js`: קריאה וכתיבה של מתכונים; רק הרשימה הציבורית נשמרת במטמון קצר בזיכרון.
- `src/pages`: מסכי האתר; כל מסך משתמש ב־CSS Module מקומי.
- `src/styles/global.css`: ברירות המחדל המשותפות בלבד.

`npm run dev` מפעיל את Vite בפורט 3002 ומעביר `/api` לפורט 5001. `VITE_API_URL` ריק כברירת מחדל; אין להוסיף אליו `/api`.

`npm run preview` מציג את הבנייה הסטטית בלבד ואינו מפעיל API. לבדיקה משולבת של הייצור, בנו את הלקוח והריצו את השרת עם `NODE_ENV=production`.

אין לשמור סודות במשתנים עם הקידומת `VITE_`: הערכים שלהם נכללים בקוד שנשלח לדפדפן.
